# Guess (0/1 guesser) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the 0/1 guesser as a pnpm monorepo: Effect 4 logic (two features, hexagonal, one package per layer), a React product and a no-framework DOM product, then write skills from the proven code.

**Architecture:** Domain and application packages are pure Effect code. Use cases follow Command + `UseCase<C>` and are built by plain constructors; only `GuessState` and `RoundsState` are Layers. Each product has a two-phase composition root and passes finished use cases plus the `ManagedRuntime` to its bridge (React hooks or `EventTarget` objects).

**Tech Stack:** TypeScript 6.0.3, Effect 4.0.6, pnpm 11 workspaces, Vitest 5.0.5, Vite 8.3.5, React 19.3.1, jsdom 30.1.3, @testing-library/react 16.3.3.

**Spec:** `docs/superpowers/specs/2026-10-23-guess-design.md` — every executor reads the spec section named in its task.

## Who runs each task

Each task has a **Model** line.
- **haiku** — the task is fully decided here. Follow it exactly.
- **sonnet** — the task has decisions left (tool config, fibers, React/DOM lifecycle, external API shape, skill writing). Sonnet makes them, writes each one down in the task's commit message, and keeps the **Produces** interface unchanged.

**Escalation rule (haiku):** if a type error or failing test is still there after 2 fix attempts, stop. Report the exact error and what you tried. The orchestrator re-runs the task with sonnet. Do not change an **Interfaces** block to make code compile.

## Global Constraints

- English at B1 level in all docs, comments, UI copy and skills.
- Write only inside this repo. `~/s4y/vocabla-mill` and `~/s4y/meridian` are read only.
- Effect **4.0.6** APIs only. Your memory is probably of Effect 3; v4 names differ. Use `Context.Service`, `Layer.effect`, `ManagedRuntime.make`, `SubscriptionRef.make/get/set/update/changes`, `FiberHandle.make/run/clear`, `Effect.forkChild/forkScoped`, `Data.TaggedClass`, `Data.TaggedError`, `Schema.decodeUnknownResult` / `Schema.fromJsonString`. If a name does not compile, look it up in `node_modules/effect/dist/<Module>.d.ts`; never guess a v3 name (`Context.Tag`, `Effect.Service`, `Effect.fork`, `Layer.scoped` do not exist or differ).
- No RxJS, no `effect-atom` / `@effect-rx`.
- Do not use these names for new types: `ViewModel`, `Store`, `Service` (except Effect's `Context.Service`), `View` for a reactive value, `Rx`, `LiveValue`.
- Every use case response has `R = never` and error type `never`. Failures become state.
- Only two Layers exist: `GuessState.layer` and `RoundsState.layer`. Use cases, adapters and ports have no tag and no Layer.
- Ports are plain TS interfaces.
- An application package re-exports (as types) every domain type its use cases return, so presentation and products import only from `*-application`.
- Allowed package dependencies are the table in Task 14. Nothing else.
- Commit steps: run them only if the user allowed commits for this run; otherwise leave the changes staged and say so.

## Review Focus

1. Two presses before a guess is ready → the second round is saved with `guess: null`, no error, and no old guess is used for a later round (Task 10, test `press while thinking`).
2. Reset while a guess is running → that guess never becomes `Ready` (Task 6, test `empty RequestGuess interrupts`; Task 10, test `reset while thinking`).
3. Bad N input (0, 300, 2.6, NaN) → clamped to 1–256, rounded, NaN ignored (Task 6, test `SetWindowSize clamps`).
4. React StrictMode mounts twice → values still update, and after unmount no subscription fiber is left (Task 11, test `StrictMode and unmount`).
5. Page reload with saved rounds → same rounds and score, and a guess is requested for them (Task 9 round trip; Task 10, test `ResumeGame requests a guess for loaded rounds`).

  - Commands (each `Data.TaggedClass` with a declared `"~response"`):

    - `makeRequestGuess(deps: { guessState: GuessState; gateway?: GuessGateway }): UseCase<RequestGuess>` — default gateway `makeLongestMatchGateway()`
    - `makeTakeGuess(deps: { guessState: GuessState }): UseCase<TakeGuess>`
    - `makeSetWindowSize(deps: { guessState: GuessState; requestGuess: UseCase<RequestGuess> }): UseCase<SetWindowSize>`
    - `makeObserveWindowSize(deps: { guessState: GuessState }): UseCase<ObserveWindowSize>`
  - Re-exports: `type Guess`, `type GuessFailed`, `type GuessGateway` (for tests of other packages).

Behaviour (spec 5.2):
- `RequestGuess`: remember `bits`. If `bits` is empty: clear the fiber handle (interrupts a running guess), set `Idle`. Else set `Thinking` and run `gateway.guess(lastN(bits, N))` in the `FiberHandle` (running it interrupts the previous guess); on success `Ready(guess)`, on failure `Failed`. Returns at once.
- `TakeGuess`: if `Ready(g)` → set `Idle`, return `g`; else return `null` and leave the state as it is.
- `SetWindowSize`: `NaN` → no change. Else round, clamp to 1–256, set, save to storage, then `RequestGuess` with the remembered bits (drops a ready guess, interrupts a running one).
- Layer start: read the window size from storage (invalid → default).
